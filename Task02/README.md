# Лабораторная работа 2
## Подготовка скриптов для создания таблиц и добавления данных

### Назначение

В данной лабораторной работе реализована утилита для подготовки базы данных SQLite на основе исходных файлов с данными.

Утилита `make_db_init.py` считывает данные из исходных файлов и формирует SQL-скрипт `db_init.sql`. Полученный SQL-скрипт содержит команды для создания таблиц базы данных и добавления в них исходных данных.

Для запуска утилиты и последующей загрузки SQL-скрипта в SQLite используется shell-скрипт `db_init.bat`.

### Требования к окружению

Для корректной работы скрипта `db_init.bat` на компьютере должны быть установлены:

- Python версии 3 или выше;
- SQLite 3;
- Bash.

Команды `python3` и `sqlite3` должны быть доступны из командной строки.

Скрипт рассчитан на запуск в Unix-подобном окружении. В Windows для запуска можно использовать Git Bash.

### Структура задания

В каталоге `Task02` находятся следующие файлы:

- `make_db_init.py` — программа для чтения исходных данных и генерации SQL-скрипта;
- `db_init.bat` — shell-скрипт для запуска генератора и загрузки SQL-скрипта в SQLite;
- `db_init.sql` — сгенерированный SQL-скрипт;
- `movies.csv` — исходные данные о фильмах;
- `ratings.csv` — исходные данные с оценками фильмов;
- `tags.csv` — исходные данные с тегами;
- `users.txt` — исходные данные о пользователях;
- `movies_rating.db` — база данных SQLite, создаваемая в результате работы скрипта.

### Запуск

Для запуска необходимо открыть терминал и перейти в каталог `Task02`.

В Git Bash скрипт запускается командой:

bash db_init.bat

После запуска сначала выполняется программа `make_db_init.py`.

Программа считывает исходные данные из файлов `movies.csv`, `ratings.csv`, `tags.csv` и `users.txt` и создаёт файл `db_init.sql`.

Затем команда SQLite выполняет созданный SQL-скрипт и загружает его в базу данных `movies_rating.db`.

### Результат работы

После успешного выполнения `db_init.bat` создаётся заполненная база данных SQLite `movies_rating.db`.

В базе данных создаются четыре таблицы:

- `movies`;
- `ratings`;
- `tags`;
- `users`.

Таблица `movies` содержит информацию о фильмах.

Таблица `ratings` содержит оценки пользователей.

Таблица `tags` содержит теги, добавленные пользователями к фильмам.

Таблица `users` содержит информацию о пользователях.

### Повторный запуск

При повторном запуске программы существующие таблицы базы данных удаляются и создаются заново.

После создания таблиц данные из исходных файлов снова загружаются в базу данных.

Таким образом, повторный запуск `db_init.bat` позволяет заново сформировать базу данных на основе исходных файлов.

### Кроссплатформенный запуск

Скрипт `db_init.bat` является shell-скриптом и начинается со строки:

#!/bin/bash

Во второй строке запускается программа генерации SQL-скрипта:

python3 make_db_init.py

В третьей строке созданный SQL-скрипт загружается в базу данных:

sqlite3 movies_rating.db < db_init.sql

Для работы в Linux необходимо, чтобы Python 3 и SQLite 3 были установлены и доступны в системном `PATH`.

В Windows для запуска скрипта можно использовать Git Bash.
