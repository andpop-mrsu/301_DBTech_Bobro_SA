# Лабораторная работа №1

## Структура файлов данных

В каталоге `Task01` находятся исходные файлы данных, скопированные из каталога `dataset`.

### Файлы CSV

- `movies.csv` — данные о фильмах.
- `ratings.csv` — оценки пользователей.
- `tags.csv` — пользовательские теги.

### Справочные файлы

- `users` — данные пользователей. Каждая запись содержит идентификатор пользователя, имя, адрес электронной почты, пол, дату рождения и профессию.
- `occupation` — список профессий пользователей.
- `genres` — список жанров фильмов.

### Файлы, созданные в ходе выполнения лабораторной работы

- `ratings_count.txt` — содержит минимальный и максимальный идентификаторы пользователей из `ratings.csv` и количество записей с каждым из этих идентификаторов.
- `sqlite.txt` — содержит версию установленной SQLite и доступные режимы вывода данных.
